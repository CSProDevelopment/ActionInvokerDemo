# Action Invoker (Android) Demo

This Android application, Action Invoker Demo, demonstrates running [Action Invoker](https://csprousers.org/help/CSPro/action_invoker.html) actions by specifying the [actions using JSON](https://csprousers.org/help/CSPro/action_invoker_execution_json.html), passing that JSON in an [Intent](https://developer.android.com/reference/android/content/Intent), and [processing the result](https://developer.android.com/training/basics/intents/result) returned by ActionInvokerActivity.

For more information about this process, see the CSPro documentation: [Action Invoker Execution from Other Android Applications](https://csprousers.org/help/CSPro/action_invoker_execution_android.html)
